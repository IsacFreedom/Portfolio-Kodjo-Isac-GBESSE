Projets

AgroPrice

  • Python
  • Prophet
  • Séries temporelles
Problème
Les prix du maïs varient selon les saisons et les régions. Les acteurs du marché agricole, les agences humanitaires et les pouvoirs publics ont besoin de prévisions pour décider.
Méthode
Données de prix du Programme alimentaire mondial (WFP) au Togo, nettoyées avec pandas (dates, prix, filtre sur le maïs blanc). Exploration par région, puis modèle Prophet pour Lomé avec saisonnalité annuelle, prévision sur 12 mois avec intervalle de confiance. Validation croisée et mesure de l'erreur (MAPE, RMSE, MAE).

CashScore

  • Python
  • Random Forest
  • SHAP
Problème
Estimer la probabilité qu'un client rembourse un crédit à partir de ses usages Mobile Money, sans historique bancaire classique.
Méthode
Jeu de données simulé (âge, fréquence et montant des recharges, régularité des revenus, épargne, score de réseau). Modèle Random Forest, probabilité convertie en score sur 100, évaluation (accuracy, precision, recall, F1) et explications SHAP pour comprendre les facteurs de décision.

Les données sont simulées : le projet illustre la démarche de scoring et d'explicabilité.

Voir le code sur GitHub
